# Comparison algorithms

## CCBS fixed-route adapter

`marl/ccbs_adapter.py` performs exhaustive continuous-time precedence search over the conflict zones generated by the existing roadmap routes. It uses the same route samples, speed, cluster clearance, dwell model, deadline, and local `SettleGuard` as the TPG comparison. The search can change temporal precedence and cannot change a spatial route. Planning time, expanded nodes, conflict-zone count, infeasibility, and the selected order are written to each episode row. This is the fair temporal-coordination comparison. It is an adapter for the IJCAI 2019 CCBS assumptions, not a claim that the authors' implementation is embedded.

Run it through the existing baseline matrix with `--methods ccbs`, or use the default list in `scripts/evaluate_hard_baselines.py`.

## Sun et al. mr-nav

The upstream repository was audited at commit `c129da1447d9854e31b1d7b970b7f48b8a553ea7`. Its released vessel environment is 2-D, uses 72 virtual-LiDAR values plus target, position, and previous scalar action, and emits one heading-angle action. `scripts/mr_nav_adapter.py` records the license, upstream commit, dimensions, and the proposed common 2-D mapping in `research/mr_nav_adapter_manifest.json`.

The policy and upstream dataset are not silently treated as a 3-D VRL result. A trained checkpoint and the upstream dataset are still required before the N=1 mapped-policy evaluation can be reported.

## Long MAPPO-V2 comparison

`scripts/run_long_comparison.sh` runs the corrected centralized-critic MAPPO-V2 with independent output directories. `TIMESTEPS` and `SEEDS` are configurable. The default is 500,000 physical steps for seeds 41, 42, and 43. Existing outputs are resumed by the paired rerun script and are never overwritten.
