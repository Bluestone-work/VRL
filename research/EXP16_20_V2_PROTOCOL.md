# EXP16–20 v2：预登记与执行说明

日期：2026-09-27。用户授权先完成 16–20，再尽量并行持续训练、评估、记录。
本协议是独立 v2 对照，不覆盖正在运行的 EXP_0016，也不把旧 EXP15 的 53.3% 当作严格配对基线。

|版本|实现|低层控制性质|
|---|---|---|
|16 v2|局部可见障碍物、三步 CV 预测、共同工作量/ETA 调度、adaptive-edge GAT-MAPPO|直接 RL|
|17 v2|在 16 上用六帧历史 GRU 预测 1/3/5 步位移与方差，历史不足回退 CV|直接 RL|
|18 v2|17 + 八个候选动作、三步解析风险评分|RL + 预测控制混合|
|19 v2|独立训练动作条件局部世界模型 ensemble，验证单步与三步滚动误差|模型实验，不虚构策略成功率|
|20 v2|18 + 通过预测验证的世界模型三步规划评分；高不确定性回退解析模型|RL + 学习模型预测控制混合|

这些是研究假设及实现贡献，尚未通过文献查新或实验证实算法新颖性；不预先宣称优于原算法或达到 85%。

## 共同条件和修复

5 机器人、14 类解剖场景等量训练分组（56 并行环境）、动态粒子 24、半径比 1.6、漂移 0.15、horizon 300、机器人半径 .0011、geodesic 接触、相同奖励。
所有新策略共同修复：vector route 接口使用血栓 station；调度后立刻刷新观测；按真实相邻位置位移计算路径，排除自动 reset 跳跃；每回合重置障碍物历史。
共同调度使用已知地图测地 ETA、当前质量与服务负载、局部血流、15 步切换代价；固定机器人顺序，5 步更新一次，目标清除立即更新。没有动态粒子风险调度项。
保留原几何观测/已知地图/规则调度，不能称完全端到端无先验导航。
预测时间单位是仿真步，非秒。障碍感知半径 .12，仅最近可见粒子；仿真 ID 只做理想跟踪关联，不作为网络输入。未见障碍不能泄漏进预测特征。风险分数不冒充校准碰撞概率。
PPO 存储原始采样动作与其 log-prob，筛选作为有效环境的一部分；执行动作另存评估轨迹。不能用筛选动作搭配原动作 log-prob。
解析预测冻结局部 Frenet 坐标系，近似当前血流与润滑，短期曲率/邻居静止近似均有误差；不是碰撞安全保证。

## 训练预算与自动任务依赖

训练 seed 42/43/44；各策略固定 3,000,000 transitions（整批向上取整）。固定约 1M、2M、3M checkpoint 都评估，不能选择最有利 checkpoint 冒充 final。
GRU 每 seed 额外 50,000 环境 transitions；真实数量在 data_manifest.json 中，向上取整到 14。
19 从该 seed 的 17 第一个 checkpoint 采集独立数据，混合其动作、噪声、随机及停驻动作。
19 的预定数据预算阶梯为 50,000、150,000：首轮失败才进行第二轮全新采集；总成本为已执行各轮之和，不隐藏失败。每轮拟合 30 epochs。若所有门槛失败，20 标记 blocked，保留模型及误差，不强行执行。
模型训练由完整几何 generation 分组拆分 80/20，避免相邻片段跨集合。holdout 用于选择模型与门槛，故是模型开发验证，不是独立最终测试。
GRU 报告对 CV 的误差比较，负结果仍运行预注册 17/18，不能把使用 GRU 等同预测改善。
世界模型必须同时：单步 obs RMSE 低于 persistence；三步滚动 obs RMSE 低于 persistence；位移 RMSE 低于观测血流/润滑运动学基线。
模型目标包括 52 维 obs 差分、局部实际位移、团队平均清除质量、团队平均墙事件（后两项是共享软标签，不声称逐机器人因果归因）。
20 只有全部候选的 ensemble 位移分歧都低于 .0045 才采用学习评分，否则退回 18。此门槛是预设启发式，不是统计安全置信界。三步 gate 用混合行为轨迹验证，不保证所有规划候选都位于训练分布。
预算必须分别报告策略学习、预测采集、世界模型各轮采集及拟合成本；不是相同总交互成本的因果比较。
独立保存组件能支持后续消融，但不能替代匹配预算的正式消融实验。

## 评估与 85% 阈值

全部固定 cuda:0，deterministic policy mean、eval mode、单线程；开发验证 seed = 72,000,000 + scenario_index × 1000 + episode_index，粒子 seed = 82,000,000 + 同偏移。
每场景 10 回合，14 场景 = 140 / checkpoint / training seed。同一清单用于所有版本，不降低障碍数量、成功定义或时间限制。
主指标：所有血栓质量清零；场景等权，再以训练 seed 为单位 mean ± sample SD。全三个 seed 到齐且均值 ≥85% 才记录开发验证达标，不代表最优性或封存测试通过。
记录全部成功/失败回合：质量清除、真实总路径、逐机器人路径、成功条件路径、每清除质量路径、墙/机器人/粒子碰撞、任务切换、规划/推理时间、动作干预、模型采用率。
未清除质量的 path_per_mass=null；成功步数、成功路径只对成功回合计算。失败回合不能因短路径而被称高效。
每回合保存位置、粒子、proposal、executed、剩余质量轨迹。碰撞是离散步事件，不宣称连续时间无穿越。
旧封存 test 不读取、不调参。这里是新开发验证分布；目前未认证生成器输出与所有历史/封存几何精确互斥，不能宣称严格拓扑外推。

## 运行与保存

独立 tmux supervisor；新目录冻结 environments/marl/scripts/configs/tests、协议、逐文件 SHA256 与 Python 软件版本。旧源码、运行中进程和历史结果不覆盖。
两 GPU 分配任务，评估固定 GPU0；最多 18 子任务，排除 CPU 6/7、线程数 1、保留 4GB GPU / 8GB RAM / 20GB disk 余量。当前依赖就绪任务不足时不空造并发。
任务错误最多重试一次，新 attempt 目录保留失败证据。不可把重试中最好的 seed 当正式结果；重复 seed 评估会使汇总达标门槛失效。
status.json/events.jsonl/logs 记录状态、命令、PID、错误；REPORT.md/results.json 周期更新。
进程断连不影响 tmux；checkpoint 是可评估策略备份，不承诺训练环境完整精确恢复。supervisor 退出或机器重启后不会自动恢复，须新登记恢复方案。
队列运行至固定 3M 阶梯和评估结束，不无限更改算法追逐验证集。未达 85% 保留负结果，再开展下一轮有依据的研究。
