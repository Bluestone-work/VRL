# 统一基准 v1：baseline 体系、失败归因与有动机的改进（2026-10-05）

分支 `research/fair-partial-observation`。全部为**开发集**结果：每种血管 30 个固定开发场景（`multicluster_benchmark_v1.development`），14 种血管，N=1/2/3。测试集（每种血管 100 个）尚未打开。完整表格见 `BENCHMARK_V1_SUMMARY_20261005.md`，配对统计见 `BENCHMARK_V1_PAIRED_20261005.txt`。

## 1. 任务与评价

- **任务**：N 个磁性集群清除同一血管树中的 4 个血栓。N=1 为单集群顺序清除，N=2/3 为多集群并行，最小间距 2 mm。场景用 `paired_environment` 生成：几何、血栓、粒子、起点池在不同 N 和方法之间完全相同，总溶栓速率固定（单集群速率 = 0.36/N）。时限 300 s。
- **高层分配 A**：t=0 时用术前血管地图计算一次。每个集群得到一个有序的血栓列表，目标是最小化"最长集群路程"（makespan），平局时比总路程。所有方法共用同一份分配。
- **信息等级**：
  - 路线图级（roadmap）：可以使用术前地图上的路线。表中标作 privileged。
  - 局部级（fair）：只有局部血管视野（4 mm）、目标血栓的直线方向、局部粒子和队友。
- **主指标：安全成功（Safe）**，必须同时满足：
  - 全部清除；
  - 累计撞壁 < 1 集群·秒；
  - 无粒子接触、无集群间接触、无集群丢失；
  - 无间距违规。
- **其他维度**：
  - Raw 成功；
  - 清除率；
  - 完成 50/90/100% 的时间（中位数，未完成按删失处理）；
  - 清除曲线下面积（AUC，完成后按清除状态计到时限）；
  - 总路径、每个血栓的路径；
  - 撞壁（均值 / 中位数 / 比例 / 最长连续）；
  - 粒子事件、间距违规时长；
  - 长时间让行次数（死锁代理）；
  - 超时率。

## 2. Baseline（14 种血管平均，Safe / Raw / T100 / 每个血栓的路径）

| 类别 | 方法 | 信息 | N=1 | N=2 | N=3 |
|---|---|---|---|---|---|
| 传统 | 规划 A + 路线跟随（route_follow） | 路线图 | 78.1 / 80.7 / 162 s / 71 mm | 87.1 / 97.1 / 90 s / 54 mm | 79.5 / 98.1 / 69 s / 61 mm |
| 传统 | 规划 A + 局部跟随（local_follow） | 局部 | 39.8 / 41.7 / >300 / 174 mm | 57.9 / 65.2 / 161 s / 169 mm | 68.8 / 85.7 / 84 s / 105 mm |
| 传统 | 规划 A + 旧反应式（plan_reactive） | 局部 | 19.8 / 19.8 / >300 | 32.9 / 36.4 / >300 | 44.3 / 55.7 / 267 s |
| 传统 | 无分配 + 旧反应式（nearest_reactive） | 局部 | 17.4 / 17.4 / >300 | 25.7 / 33.8 / >300 | 31.9 / 47.9 / >300 |
| 学习 | BC 图 transformer 学生（模仿 route_follow） | 路线图 | 37.4 / 38.6 / >300 | 52.4 / 69.3 / 147 s | 56.4 / 81.4 / 93 s |
| 学习 | BC 局部 MLP 学生 | 局部 | 28.3 / 37.6 / >300 | 38.8 / 59.3 / 213 s | 43.6 / 74.0 / 133 s |
| 学习 | 局部学生 + DAgger 第 1 轮 | 局部 | 41.7 / 45.2 / 265 s | 52.4 / 66.4 / 133 s | 52.4 / 77.6 / 96 s |
| 分层（规划 + 跟随） | route_follow 本身就是"高层分配 + 低层跟随"；学习型分层见 §4 的 I2 | — | — | — | — |

几点结论：
- **高层分配 A 有用。** plan_reactive 比 nearest_reactive 在 N=2 高 7.2 pp，在 N=3 高 12.4 pp。
- **并行有用。** 路线图级方法的完成时间从 N=1 的 162 s，降到 N=2 的 90 s、N=3 的 69 s。
- **学习类 baseline 都没有超过对应的传统方法。** 主要问题是撞壁：BC 学生每个 episode 撞壁 9–29 s，因为它在 1% 的停车样本上学不到停车（停车召回约 10%）。
- **DAgger 相对等步数 BC 对照有显著增益**（N=1/2/3 分别 +10.2 / +11.9 / +11.9 pp，置信区间不跨 0），但在留出血管上不显著，而且仍低于手写的局部跟随。

## 3. 失败归因 → 动机

| 发现 | 证据 | 引出的改进 |
|---|---|---|
| F1：旧控制器在分叉处来回摆动，进不去锐角侧支 | 仿真只在机器人沿轴向越过边的端点时才换边；MCA 穿支是锐角分出的。按站点做路线跟随时，单集群 0/10 能清完 | **I0**：按边级、分叉分组的路径跟随，锐角处先过冲再回转。路线图级 N=1 达到 10/10 清完，7/10 安全 |
| F2：局部跟随的失败 93% 是极限环 | 15 个失败里，14 个是在两个前沿之间来回切换。测地距离长期不变，机器人一直在动 | **I1**：前沿 tabu 记忆（30 s 内放弃过的前沿降权） |
| F3：局部信息下分支选错 | 手写前沿打分与"测地最近前沿"只有 83.1% 一致 | **I2**：学习的前沿选择器（训练时用特权标签，推理时只用公平特征） |
| F4：N=3 的撞壁来自间距护盾 | 去掉间距滤波后 wall ≥ 1 s 只有 2.9%（但 27% 的 episode 发生集群间接触）；加上投影护盾后是 14.3% | 只沿管轴避让（tube）、后退（backoff）、完成后原地等待（hold）三种护盾变体：都是负结果，见 §5 |
| F5：近距离相遇有 93% 发生在分叉 3 mm 以外 | 管道里的"跟车 / 迎面"冲突占主导，不是分叉口的冲突 | 冲突感知分配：负结果，见 §5 |

## 4. 改进结果（局部级，配对，14 种血管，95% 置信区间按"血管–场景"两级 bootstrap）

**I1 tabu 记忆 vs 局部跟随（Safe）**

| N | 全部血管 | 留出血管 | 场景更好 / 更差 |
|---|---|---|---|
| 1 | **+25.2 pp** [+17.1, +33.3] | +20.7 pp [+8.7, +33.3] | 107 / 1 |
| 2 | **+20.7 pp** [+10.0, +31.4] | +21.3 pp [+8.0, +35.3] | 100 / 13 |
| 3 | +6.4 pp [−0.7, +13.6] | +2.0 pp（不显著） | — |

- I1 的绝对值：N=1 达到 65.0%，路线图级是 78.1%，局部跟随是 39.8%，补上了约 66% 的信息差距。超时从 58% 降到 33%，每个血栓的路径从 174 mm 降到 92 mm（I2 为 86 mm）。
- I1 只试过一个超参数（30 s），没有调参。

**I2 学习的前沿选择器**
- 安全成功与 I1 打平：N=1/2/3 分别 +1.2 / 0.0 / +0.5 pp，置信区间都跨 0。
- N=2 时效率略有提升：T100 快 10.7 s [−19.1, −2.5]，路径短 21 mm [−37, −5]。但 AUC 也略低（−2.0 pp）。
- 结论：学习的选择器在决策准确率上大幅领先（98.0% vs 83.1%），但闭环收益很小。I1 已经消除了大部分代价高的错误。

**与路线图级的剩余差距**：I2 − route_follow 在 N=1/2/3 分别是 −11.9 / −8.6 / −3.8 pp。

## 5. 负结果（全部保留）

- **tube 护盾**（只保留沿管轴的修正）：N=3 撞壁大幅下降，但 Raw 从 97.9% 降到 92.9%，长时间让行变多，Safe 不变。
- **backoff**（让行方沿管轴后退）：N=3 的 Safe 从 82.1% 降到 76.4%，间距违规从 3.6% 升到 17.1%。
- **hold**（完成自己任务后原地等待）：没有收益，超时增加。
- **冲突感知分配**（makespan + λ·占用冲突）：λ=0.5 / 2 时 Safe 下降 2–6 pp。
- **局部跟随的分叉访问计数记忆**：+0.7 pp，不显著。
- **线下模仿准确率很高，闭环却较差**：图学生在训练集上方向余弦 0.994，闭环 Safe 只有 37–56%。

## 6. 局限

- 只有开发集结果，测试集未用。学习方法只有单个种子。
- 2 mm 间距、磁场独立驱动、局部 4 mm 视野、2.5% 噪声都是工程假设，没有硬件标定。
- 纯 RL（PPO/MAPPO 从零训练）和学习型分层 RL（Codex 的 V-CTPG-HRL、选项 HRL）还没有接入这个统一基准。Codex 在测量式传感下的结果（清除率 13–80%，安全成功几乎为 0）因为设定不同，不能直接并列比较。

## 7. 下一步

1. 把纯 RL baseline（参数共享 PPO，局部观测 + 目标槽位）和学习型分层 RL 接入同一基准，补齐三类 baseline。
2. 以 I1+I2 为局部级主方法。在 N=3 时，针对管内跟车 / 迎面冲突设计新的协调机制（F4/F5），这是剩下最大的安全缺口。
3. 学习方法用 3 个种子；确认主方法后，在测试集上每个方法只评估一次。
