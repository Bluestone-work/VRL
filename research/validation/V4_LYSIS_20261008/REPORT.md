# Benchmark v4：多集群破栓效率 + 避壁 —— 基线与消融（开发集 pilot）

日期 2026-10-08（夜间自动运行）。数值表由 `scripts/report_lysis_v4.py` 生成到 `TABLES.md`，本文只摘要并解释。
全部是开发集（`multicluster_benchmark_v1` development，14 解剖 × 10 场景 × N=1/2/3 = 420 回合/方法），测试集未打开。
学习类方法均为**单种子、≤110 分钟的 pilot**，不是正式结论。

## 1. 任务与算法更新（按 10-08 用户决定）

- 去掉动态碎片避障与障碍碰撞指标；保留“尽量不碰血管壁”。环境 = benchmark v2/v3 的 union-of-tubes 管腔、术前分配 A、
  图像感知（双平面合成图像→检测→跟踪）、2 mm 间距护盾；无障碍、无示踪粒子。入口 `scripts/benchmark_lysis.py`。
- 控制器只读可部署信息：术前地图（中心线、健康半径、血栓位置）、图像估计的集群位置、血栓是否仍可见。真值只用于指标和训练奖励。
- 四类指标（每回合）：
  - 破栓效率：T50/T90/T100（未达到按 300 s 截尾计入均值）、清除 AUC（全时域）、路径；
  - 破栓完整度：最终清除率、全部清除率；
  - 集群互不影响：间距违规 pair·s（d < 2 mm）、无干扰回合比例、偶极耦合暴露 ∫Σ(d_min/d)³dt（d<4 mm，未标定的磁干扰代理）、TPG 等待时间；
  - 碰壁：累计壁接触 robot·s、最长连续接触、壁接触 ≥1 s 比例。
  - 复合：Relaxed = 全清 ∧ 壁 < 5 s ∧ 无干扰；Strict = 全清 ∧ 壁 < 1 s ∧ 无干扰。

## 2. 本文方法（learning，分层）

| 层 | 内容 | 学习？ |
|---|---|---|
| 高层 | MAPPO 在线协同分配：共享 actor（自身观测：各血栓可见性、到我/到最近同伴的术前测地距离、谁在追、A 先验；自身停滞/等待）+ 集中 critic（全队可部署观测）；事件触发（目标消失 / 每 5 s）；logits = MLP + w·A 先验，未训练时等于 A | 是 |

| 低层 | 时序 Transformer 残差 PPO（3 层、4 头、32 步历史），残差加在经典先验（拓扑修正追踪 + 壁护 + 到栓减速）上，输出零初始化 | 是 |
| 安全层 | 间距护盾（所有方法共享） | 否 |

## 4. 主结果（N=1 / 2 / 3，每格 140 回合；完整表与配对 CI 见 TABLES.md）

“经典最强”= A + TPG + 拓扑修正追踪 + 壁护 + 到栓减速（`classical_settle`，今晚加入，见 §5）。

| 方法 | 全清 % | 清除率 % | T90 s | AUC | 壁接触 robot·s | 无干扰 % |
|---|---|---|---|---|---|---|
| 经典最强 classical_settle | 89.3 / 95.7 / 94.3 | 96.6 / 98.4 / 98.1 | 166 / 102 / 78 | .690 / .815 / .864 | 4.1 / 2.8 / 3.1 | 100 / 99.3 / 99.3 |
| STPG（AAAI 2025） | 同左 / 95.7 / 94.3 | — / 98.4 / 98.1 | — / 101 / 78 | — / .817 / .864 | — / 2.8 / 3.1 | — / 100 / 99.3 |
| PAC-NMPC（CASE 2025） | 85.0 / 90.7 / 90.0 | 94.8 / 97.3 / 97.2 | 177 / 110 / 89 | .670 / .804 / .853 | **1.4** / 4.3 / 4.4 | 100 / 100 / 100 |
| Turbo（NMI 2026，110 min） | 1.4 / 18.6 / 30.0 | 33.7 / 56.1 / 68.4 | 300 / 283 / 257 | .212 / .374 / .501 | 1.3 / 4.8 / 6.6 | 100 / 100 / 100 |
| 本文（学习分配 + 残差 PPO） | 86.4 / 92.9 / 93.6 | 95.6 / 97.4 / 97.9 | 177 / 113 / 84 | .664 / .797 / .854 | 5.2 / 6.7 / 4.3 | 100 / 100 / 100 |

STPG 在 N=1 无协调问题，等同经典最强。

读法：

1. **今晚 pilot 的本文学习方法没有超过经典最强**：全清 −2.9 / −2.9 / −0.7 pp，T90 +11 / +11 / +6 s，壁接触更多。差距全部来自学习残差（§5）；学习分配器本身与 A 基本相同。另一个变体（残差从“只有壁护”的较弱先验学起）在 N=3 全清 +3.6 pp（CI 不含 0），但更慢、擦壁更多，见 §5。
2. **三个基线**：STPG 与经典最强持平（N=2 T90 −1.8 s，CI 不含 0，量很小）；PAC-NMPC 全清低 4–5 pp、T90 慢 7–11 s，但 N=1 壁接触最低（1.4 vs 4.1）；Turbo 直接输出速度，在同等小预算下远未学会（全清 1–30%），只能算预算受限的下界，正式对比需要更长训练（需你确认）。
3. **多集群的价值很清楚**：N=1→3 时 T90 从 166 s 降到 78 s，AUC 从 .69 升到 .86，间距违规接近 0。

**从较弱先验学习（residual_guard_s0：先验只有壁护、没有手写减速，同样预算 95 min）——今晚唯一有正信号的学习结果**：

| N | 全清 % 学习 / 经典最强 | 清除率 % | T90 s | 壁 ≥1 s 回合 % |
|---|---|---|---|---|
| 1 | 86.4 / 89.3 | 95.8 / 96.6 | 186 / 166 | 9.3 / 2.9 |
| 2 | 96.4 / 95.7 | 99.0 / 98.4 | 118 / 102 | 10.0 / 2.1 |
| 3 | **97.9 / 94.3**（配对 +3.6 pp [+0.7, +7.1]） | **99.3 / 98.1**（+1.2 [+0.4, +2.2]） | 86 / 78 | 11.4 / 1.4 |

（表中为加了评估期后置壁护 post_guard 的版本，与不加差别很小。）

- PPO 自己学到了到栓停靠（相对无减速先验，N=3 的 T90 快 22 s），而且**不会出现手写减速在高流速下的失败**：coronary_rca（训练时没见过的解剖）10/10 全清，手写规则只有 7 / 6 / 5。
- 代价是更慢（T90 +8 到 +20 s），轻微擦壁更多（壁 ≥1 s 的回合约 10%，但均值仍 < 6 s）；N=1 在 pulmonary / mca 上丢了几个场景。
- 所以学习确实能解决手写规则的失败模式，但目前是用效率和轻微擦壁去换的。下一步最直接的组合是：经典减速 + 学习的“何时放弃减速 / 何时贴栓”门控，或者对残差在已成功区间加 KL 约束。

**时序结构消融**（同预算、同 settle 先验，相对经典最强的全清 pp，N=1 / 2 / 3）：Transformer −2.9 / −2.9 / −0.7；GRU −24.3 / −13.6 / −2.9；MLP −25.7 / −5.7 / −0.7。T90 分别慢 +11 / +13 / +6、+60 / +64 / +45、+54 / +49 / +24 s。在三种结构里 Transformer 时序记忆明显最好，但三者都没有超过不加残差的先验。

**效率上限分析**（`ideal_bound.jsonl`）：理想 T100 = 按 A 的路线以 1 mm/s 全速行驶 + 纯溶解时间、无等待。经典最强在**已清完的场景**上实际 T100 / 理想 = **1.00 / 1.03 / 1.02**（PAC-NMPC 1.03）。改成把溶解时间也纳入的最优分配，理想 T100 只再降约 1.5 s（2%）。也就是说，在当前 v4 设定下，已成功场景的效率基本到顶了。

**剩余可提升空间只在失败场景**：可行（理想 T100 ≤ 300 s）场景里，经典最强每个 N 只剩 7 / 7 / 8 个失败（≈5%）。其中 12 个在 coronary_rca：减速规则在高流速下顶不过血流，停在栓前 0.3 mm 内（不加减速时这些场景都能清完）。其余是 popliteal / pulmonary 卡壁和个别超时。N=1 另有 8 个场景物理上 300 s 内清不完（femoropopliteal 等长血管）。

## 6. 结论：本文算法要调到什么程度

- **要达到的线**（开发集，配对）：全清 ≥ 经典最强 + 3 pp（即每个 N 修好 5 个以上失败场景），T90 不慢于 +1 s，壁接触 ≤ 3 s，无干扰 ≥ 99%。在已成功场景上，效率最多还能提高 2–3%。所以“学习更快”在当前设定下没有可证明的空间，学习的贡献只能放在**鲁棒性 / 自适应**上。
- **学习最有希望的位置**（有明确失败归因做 motivation）：
  1. 流速自适应的到栓停靠：用估计速度判断“推不动”就不减速。coronary_rca 一个解剖就占失败的一半以上，而且它属于留出解剖。今晚已经有证据表明 PPO 能学会这一点（residual_guard_s0 在 coronary_rca 上 10/10 全清），缺的是不牺牲其他场景效率。
  2. 卡壁脱困：失败中 wall ≥ 5 s 的那部分。
  3. 执行器失配 / 感知退化下的稳健性：压力测试里经典方法掉 2–4 pp、T90 慢 11–14 s，这块有空间，但今晚的残差 PPO 还没学到。
- **学习残差的写法要改**：今晚的版本在所有步上都加修正，在接近最优的先验上纯粹添乱。下一版应该（a）只在检测到风险或停滞时介入，其余时间严格等于先验；（b）加 KL / 幅值约束；（c）训练集按失败类型做课程，包括高流速、失配增益和卡壁初态。
- **如果希望多集群协同本身成为学习的主贡献**，当前设定给的空间不够：固定总催化预算 + 2 mm 间距下，A 已接近最优，帮忙也不划算。需要你决定是否改任务设定，例如血栓尺寸 / 溶解速度在术前不确定、需要在线估计，或允许受控的协同溶栓并把干扰代价计入指标。这会改变 benchmark，需要你拍板。
- Turbo 需要按原文规模的训练（多小时、多种子）才能算公平基线；今晚的数值只能作为下界报告。
