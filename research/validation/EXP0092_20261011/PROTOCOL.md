# EXP0092 预登记（2026-10-11 09:4x，基于 EXP0091 调参集结果，开发集结果出来之前）

## 依据（只用了调参集）
- EXP0091 的 κ 网格：κ = 0 最优，不确定性锚定没有带来收益。
- V5 调参集上，Fixed Settle 全体 Strict 85.2%，所有选择器 77–81%，SwitchSettle 75.3%。差距集中在 s = 1.5，Fixed Settle 70.4%，选择器 59–67%。
- 原因：选择器以 SwitchSettle 为锚。在延迟 1 时 SwitchSettle 处于 Adaptive 模式，在强扰动下会误触发释放。

## 改动
**双锚定**（`dual_anchor=1`）：每一步用预测器在两个可部署规则之间选择锚，即 SwitchSettle 的输出和 Fixed Settle（= learner-off）指令，取预测代价更低者；其他候选要比这个锚好 δ 才能替换。Adaptive / Fixed 两种模式之间的切换由此从固定的帧龄阈值，改为由从历史学到的预测来决定。这是学习预测器可能真正起作用的位置。

## 流程
1. 调参集：在 `tune` 与 `tune_v5` 上评估 `sel_learned_fb`（预测器 A）和 `sel_online`，均为 dual_anchor = 1、κ = 0。
2. 采纳条件：学习版在两套调参集等权平均的 Strict 上超过 EXP0091 的 κ = 0 版本。满足才进入开发评估（A / B / C 三个预测器种子 + F，困难矩阵 + V5），并使用与 EXP0091 相同的"达标"判据（`scripts/gate_exp0091.py`）。
3. 达标后才进入密封测试（协议同 EXP0091）。若 EXP0091 与 EXP0092 均未达标，则停止，不进入测试，如实报告。
