# EXP37：actor 学习率 3e-5 vs 1e-4（续训 + 里程碑选模）——最终结果

两组都从 EXP35 unit_speed 500K 出发，各续训 500K × 3 seed，每 10 万步做一次开发集评估（100 布局，确定性动作）。

开发集完整清栓率（100K / 200K / 300K / 400K / 500K）：

| 组 | seed42 | seed43 | seed44 |
|---|---|---|---|
| low_lr | 56 / 52 / 49 / 35 / 53 | 51 / 50 / 27 / 56 / 47 | 67 / 54 / 54 / 73 / 62 |
| control | 54 / 26 / 19 / 49 / 38 | 74 / 23 / 32 / 42 / 41 | 36 / 63 / 36 / 66 / 41 |

- 最终 500K：low_lr 54.0%，control 40.0%，父权重 63.7%。两组续训都退化，低学习率退化更慢。
- 按独立选择集（seed base 950000000，父权重也是候选）选模型后，low_lr 选中 100K / 父权重 / 400K，对应开发集 56 / 79 / 73（69.3%）。这只说明退化之外有波动，可以靠选模捞回，不是训练本身带来的提升。
- control 组按同样规则选模：选中 100K / 父权重 / 父权重，开发集 54 / 79 / 60（64.3%）；6 个候选中有 2 个 seed 选回了父权重。
- 选模后对比：low_lr 69.3%，control 64.3%，父权重 63.7%。差距主要来自 seed44：low_lr 的 400K 在选择集 71%，开发集 73%。只有一个 seed 受益，不足以说明低学习率有效。
- 结论：仅改学习率解决不了退化。退化的根因分析见 `EXP0035_FAILURE_ATTRIBUTION_20261001/FAILURE_ANALYSIS_EXP35.md`。
