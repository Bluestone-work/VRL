# EXP0091 预登记（2026-10-11，任何 EXP0091 控制结果之前）

## 动机（来自 EXP0090）
1. 预测辅助选择在困难矩阵上超过所有基线，但学习预测器与在线估计器在控制上不可区分。
2. 在 V5（旧流量设定、延迟 1）下比 Fixed Settle 差 6–13 pp。
3. "种子"只体现在同一份数据上训练的预测器成员上。

## 改动
1. **不确定性感知锚定**（`marl/dyn_select.py`，参数 kappa）：只有当预测代价改进超过 `delta + kappa·W_PROG·sqrt(σ_rule² + σ_cand²)` 时才替换规则指令，σ 为 1.2 s 位置预测标准差。
   - 这个机制依赖不确定性是否校准。学习集成在 val 上 2σ 覆盖率为 0.96，在线估计器只有 0.70，因此它是学习组件可能真正起作用的地方。
   - 在线估计器（F）使用同一规则，σ 用它自己的 rmse 估计，公平对照。
2. **三个完全独立的预测器种子**：A（EXP0090，数据种子 2121000000+）、B（+5e6）、C（+1e7）。每个种子都有自己的数据采集和自己的 3 成员集成；回退阈值统一为 0.0445 mm（A 在 val_train 上的 p95，事先固定）。
3. "本文"定义为 `sel_learned_fb`（学习预测 + 不确定性锚定 + 认知不确定性回退），调参与评估都用固定的 W1 权重。

## 调参（只在调参场景上进行）
- 场景：困难调参集 `--protocol tune`（训练解剖，种子 2124000000+，面板 low / high / strong / variable）和 V5 调参集 `--protocol tune_v5`（旧流量、延迟 1、s = 0 / 1 / 1.5，训练解剖，种子 2125000000+）。两者与 V5 开发集、EXP0073 场景、预测器数据、测试池都不相交。
- 网格：kappa ∈ {0, 1, 2, 4}，分别对"本文"（预测器 A）和 F 调参。
- 选择规则：两套调参集的 Strict 等权平均最高者入选；平分时取壁接触更低者。选出的 kappa 同时用于 B 和 C。

## 开发评估与"达标"判据（事先固定）
在困难矩阵（252）和 V5 开发集（s × N × 14 解剖 × 10 = 1260）上评估本文 A / B / C、F、learner-off、SwitchSettle、Fixed Settle、STPG、PAC-NMPC。"达标"须同时满足：
1. 本文 3 种子均值的 Strict，在困难矩阵整体上不低于最强基线；在 V5 每个 s（对 N 取平均）上也不低于最强基线；
2. 本文（3 种子按场景取均值）相对 F 的配对 Strict 差值，在困难矩阵 + V5 合并后为正，且 95% CI 下界 > 0（学习组件可归因）。

只有达标才进入密封测试。不达标则如实报告，不进入测试，也不据此撰写"本文优于"的论文结论。
