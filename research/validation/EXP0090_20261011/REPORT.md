# EXP0090 总报告：学习导航的诊断、预测辅助选择与公平对比（2026-10-11）

开发集结果，非密封测试。困难矩阵每个面板 42 个配对场景（训练解剖 27 + 留出解剖 15）；V5 每个 s×N 格 140 个场景。
PAC-NMPC、STPG 是**本地适配基线**，不是作者实现的复现。协议、事先固定的选择规则见 `PROTOCOL.md`，审计见 `../EXP0090_AUDIT_20261011/AUDIT.md`。

## 1. 审计要点
- nav_tf_v3 s7101 / s7102 / s7103：500 updates、约 1.0 M agent steps，只有 scene_seed_base 不同，作为近同配方 3 种子。V5 时期的 nav_tf_v3_s0 配方不同（评估残差尺度 .5），不并入。
- 旧 `report_nav_decomposition.py` 把未达 T90 的回合删掉，和 T90_300 混用。本报告所有表都同时给 T90_300、达到比例和 conditional T90。
- 执行顺序：动作 → WallGuard（停滞重规划 + 近壁投影）→ TPG hold → spacing shield。学习动作会被覆盖，诊断见 §4。

## 2. 方法：预测辅助指令选择
- 学习部分：动作条件化的短时运动预测器（`marl/dyn_predictor.py`），3 个种子组成集成。
  - 输入只有可部署量：延迟图像得到的位置 / 速度历史、帧龄、完整的已发指令队列、术前地图和路线特征。
  - 输出：0–1.2 s 的真实位移（含延迟补偿），附带不确定性。
  - 未来真值、流速和响应增益只作训练标签。
- 选择器（`marl/dyn_select.py`）：每步对规则指令、learner-off 指令、停止、多方向 × 多速度候选做预测打分。代价项包括路线进展、接近血栓、有效驻留、壁风险、间距风险、不确定性和空等惩罚，并以规则为锚：只有明显更优才替换。
  - 执行器约束不变，|cmd| ≤ 1。
  - WallGuard、TPG、shield 照常作用。
- 预测精度（留出解剖，1.2 s 位置 RMSE）：

| 预测器 | RMSE | 1σ 覆盖率 | 2σ 覆盖率 |
|---|---|---|---|
| 学习集成 | **0.128 mm** | 0.81 | 0.96 |
| 在线仿射估计器 | 0.166 mm | 0.50 | 0.70 |
| 名义动力学 | 0.546 mm | — | — |
| 常速度外推 | 0.733 mm | — | — |

  - 学习集成接近理想校准（高斯分布的 1σ / 2σ 覆盖率应为 0.68 / 0.95），在线估计器的覆盖率明显偏低。
  - 窄管（间隙 < 0.1 mm）下两者都变差：0.356 vs 0.361 mm。
  - 图：`prediction/fig_prediction.png|pdf`，表：`prediction/PREDICTION_REPORT.md`。
- 事先登记的选择流程：
  1. 在调参场景（训练解剖，种子与评估集不相交）上选权重：W1；
  2. 同样在调参场景上选"本文"变体：G = `sel_learned_inv`（学习预测 + 反解学到的流 / 响应 belief 生成候选），按规则以 Strict 70.4% 选中，与 D 打平后以壁接触更低胜出；
  3. 回退阈值固定为 0.0445 mm。

## 4. 执行诊断（learner-off / nav_tf_v3）
nav_tf_v3 的残差使指令平均偏离零残差路径约 0.03–0.11（偏离超过 0.05 的 live 步占 13–99%）。WallGuard 覆盖 0–12% 的 live 步，spacing shield 几乎不触发，TPG hold 占 0–50% 的步（多集群场景）。
B（31.6%）低于 A（40.1%），配对差值 −8.5 [−12.8, −4.2] pp：**PPO 残差引入的偏移本身就是失败来源**。辅助 belief（C）减轻了退化，但仍低于 A。

## 6. V5 正式开发集（legacy 流量，延迟 1，s = 0 / 1 / 1.5）
本文 G 在 V5 上**全面差于** learner-off / Fixed Settle：
- s=0：−7 到 −13 pp；
- s=1：−6 到 −8 pp；
- s=1.5：N=1 / 2 为 −9 / −12 pp，N=3 为 −0.7 pp。

只有相对 SwitchSettle 时，s ≥ 1 下 +4 到 +33 pp。原因是 SwitchSettle 在延迟 1 时一直处于 Adaptive 模式，Adaptive 在脉动流下误触发释放。

V5 上最强的是 Fixed Settle / learner-off 和 nav_tf_v3 s7101。原因推断：选择器和预测器针对按解剖标定的强流量调参和训练，V5 是弱流的 legacy 设定，W1 的激进权重在那里反而造成多余移动。**这是一个明确的泛化缺口**。完整表见 `v5_report/REPORT.md`。

## 7. 结论与需要更多证据的地方
1. 真实瓶颈：PPO 残差在接近最优的先验上只会添乱（B < A）；强流、延迟下的瓶颈是"在不确定动力学下选择推进 / 等待的时机"，规则写不好。
2. 有效的修改是预测辅助选择：在困难矩阵上全面超过最强规则（+12 pp）和 learner-off（+20 pp）。但在控制效果上，学习预测与在线估计器不可区分，**不能把收益归因于"学习"本身**。
3. 退化场景：困难矩阵的低延迟面板（−7 pp，CI 跨 0）、全部 V5 设定（相对 Fixed / learner-off）。
4. 仍需要：
   - 选择器在 V5 设定下的独立调参，或让权重随条件自适应；
   - 3 个以上独立训练种子的完整重训（目前 D 的种子差异只来自预测器）；
   - 密封测试；
   - 真实磁场耦合和像素级检测。
