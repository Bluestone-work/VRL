# Benchmark v5：已知几何 + 个体化 / 时变动力学 —— 学习导航 pilot（2026-10-08 下午）

开发集，14 解剖 × 10 场景 × N=1/2/3，每格 140 回合，图像感知。学习方法全部是单种子 120 min pilot；测试集未打开。
扰动模型 `marl/physio_variation.py`（参数在出任何 v5 结果之前登记），强度 s：0 = v4 理想；1 = 登记的生理范围；
1.5 = 分布外（训练只用到 1.25）。扰动包括：脉动血流（心率 50–120、两谐波波形）、个体平均流量、集群响应增益 / 漂移 /
方向偏差 / 延迟、窄管形变减速、近壁阻力、壁面黏附、溶解速率。

## 1. 本文导航方法（v3，`scripts/train_lysis_nav.py`）

- 在术前路线的 Frenet 坐标系里做纯 RL 导航。动作 = 沿路线速度（相对“到栓减速”速度的修正）+ 横截面内的瞄准偏移。
- 网络：因果 Transformer，3 层，32 步（3.2 s）历史。
- 训练：PPO + v5 域随机化，加控制先验正则（Rana 2023 BCF 思路，β 0.5 → 0.02）。
- 共享的壁护和间距护盾作用于所有方法。
- 迭代记录：
  - v1 学会了停住，崩溃（γ=0.98 时溶栓奖励远在视野之外）；
  - v2 先验只放在 loss 里，结果全清只有 49–56%（a=0 本身就是“不减速追踪”，在 v5 下失败）；
  - v3 改为速度相对先验后不再退化；
  - v4（更难课程的微调）在跑。

## 3. 结论

1. **v5 让所有方法都退化**：经典最强在 s=1 全清 −4 / −5 / +1 pp，T90 慢 9–22 s；s=1.5 下壁接触 ≥1 s 的回合约占 22%。这为“需要自适应”提供了真实的动机。
2. **本文学习导航 v3 是第一个不退化的学习导航**：在 s=0 / 1 / 1.5 上与经典最强基本打平。N=2 小幅占优，N=3 小幅落后，都在 CI 边缘。它还**没有超过**经典最强，所以不能宣称 SOTA。
3. **基线**：
   - STPG 与经典最强持平；
   - PAC-NMPC 壁接触 ≥1 s 的比例最低（s=1.5 时 4–9% vs 22%），但全清低 6–10 pp；
   - Turbo 式直接 RL 在同预算下基本学不会；
   - “停滞即取消减速”的手写自适应在脉动流下反而误触发，比固定减速差 11–27 pp。这个反例说明：自适应规则很难手写。
4. **剩余失败的归因**：大多是无壁接触的超时，集中在脑 / 冠脉动脉（mca、basilar、coronary、ica）。失败场景的个体流量（1.3 vs 1.07）和脉动幅度（0.47 vs 0.37）更高。典型情况是 mca 2600000009：栓前逆流峰值约 1 mm/s，集群在栓前 0.2–1.3 mm 处徘徊 60 s。这是学习策略最该赢的地方（择机前进、贴近低流速区），但 120 min 内还没学到。

## 4. 后续迭代

- **v4（负结果）**：从 v3 热启动，换更难课程（s∈[0.5, 1.5]，困难训练解剖 ×2），先验拉力降低（β 0.1 → 0.02）。s=1 时全清 65.0 / 73.6 / 79.3%（v3 为 85.7 / 92.9 / 92.9%），T90 慢 20–45 s，壁 ≥1 s 的回合 21–23%。策略偏离了先验又没学到更好的行为，已停止其余评估；v3 仍是学习导航的参照。
- **ECG 相位（负结果）**：配方同 v3，观测里加心电相位（sin, cos）。s=1 时相对经典最强：全清 −7.9 / −1.4 / −0.7 pp，T90 慢 11–14 s，壁接触略少。相位信息没有变成更好的择机，反而让策略整体变慢。
- 之后：3 种子的正式训练和更长预算需要确认。
- PAC-NMPC 在避壁上的优势值得借鉴：可以把它当作学习策略的安全层或教师。

## 5. 可行性上界（特权 oracle，只用于分析）

`FlowOracle` 知道真实位置、集群处的瞬时血流和真实响应参数，并把它们反解掉；接近血栓时会利用近壁的低流速区。
s=1 下与经典最强对比（配对差值）：

| | 全清 % N=1 / 2 / 3 | T90 s | 壁 ≥1 s % |
|---|---|---|---|
| 经典最强 settle | 85.7 / 90.7 / 95.0 | 188 / 124 / 87 | 7.9 / 12.1 / 10.7 |
| oracle（全知） | 89.3 / 97.1 / 96.4（+3.6 / +6.4 / +1.4 pp） | 179 / 108 / 79 | 4.3 / 2.9 / 2.1 |
| oracle 不知道血流 | 66.4 / 75.0 / 74.3 | 218 / 158 / 134 | |
| oracle 不知道响应 | 86.4 / 95.0 / 95.7 | 184 / 113 / 82 | |
| oracle 只有精确定位 | 67.9 / 76.4 / 76.4 | 217 / 155 / 131 | |

结论：v5 下学习方法能拿到的空间是真实的，但不大：全清最多约 +2 到 +6 pp，T90 快 8–16 s，壁 ≥1 s 的回合少一半以上。
其中主要来自**估计并补偿瞬时血流**，其次才是集群响应。学习方法应该把"从速度历史里估计流场"作为显式目标，比如加辅助预测头或世界模型。
