# EXP0052 same-layout coupling control

Registered 2026-10-04 after the main and originally registered stress batches completed. This is a post-hoc development diagnosis, not confirmation.

The main pool (1820000000–1820000011) and the synthetic-coupling pool (1850000000–1850000003) have different layouts. Therefore a main-to-stress difference cannot be attributed to coupling alone. Three learned hierarchical attempts violated spacing in the latter pool; these original outcomes remain unchanged.

Evaluate ALL 14 original stress arms on ALL four original stress layouts with coupling alpha=0 instead of alpha=0.1. Check identical initial snapshots, physical configurations, sensor/supervisor settings, policy durations, checkpoint digests and shared source hashes. The only intended treatment is the synthetic actuator response parameter. Do not select favorable training seeds or replace failed attempts. Report the pairwise difference at the scene level and retain the small four-scene scope.

Neither alpha value is a calibrated magnetic field model. This control can distinguish numerical sensitivity to the specified synthetic coupling from layout difficulty; it cannot establish physical magnetic independence or unconditional safety.
