# EXP0064：短时壁风险残差与滞回局部护盾

2026-10-07，沿用 EXP0062/EXP0063 的图像感知、物理、动作执行、奖励和开发种子协议；不修改 PPO/DAgger 权重，不访问 sealed/test 数据，不覆盖既有输出。

## 目标

验证一个不读取仿真器壁接触真值的局部风险残差，是否能在 `all_semantic + wallguard` 的基础上减少长时间贴壁，同时不破坏障碍物语义绕行。

风险输入仅为：

- 图像检测得到的位置和有限差分速度；
- 术前地图匹配轴线、健康半径和径向偏移；
- 当前局部命令及其外向分量；
- 短时径向偏移增长和低速停滞。

实现位置：`marl/risk_navigation.py`；评估入口：`scripts/evaluate_progress_navigation.py`。

## 控制结构

- 前方检测到障碍时，语义绕行命令具有最高优先级，风险 guard 不覆盖该命令。
- 无前方障碍时，风险分数超过高阈值并连续确认后进入 `risk_guard`。
- 低阈值、最小保持时间和退出后偏移重武装条件共同抑制抖动。
- 风险分数以外向速度和偏移增长为主，静态地图偏移仅在接近/超过健康可用半径时起作用。
- guard 保留沿路分量，只逐步削弱外向分量并加入轴线方向纠偏。

## Pilot 过程

四个已知回归解剖、开发 seeds `2600000000–2600000005`，每轮 24 个 episode。每轮均输出独立 JSONL、manifest 和 audit，不混用历史源快照。

### v1：初始残差

| 指标 | all_semantic | risk_hysteresis |
|---|---:|---:|
| Task | 11/24 (45.83%) | 8/24 (33.33%) |
| Strict Safe | 3/24 (12.50%) | 0/24 (0.00%) |
| RSafe | 6/24 (25.00%) | 1/24 (4.17%) |
| 壁接触 s/局 | 42.371 | 66.691 |
| 静态事件/局 | 3.833 | 1.083 |
| 动态事件/局 | 1.208 | 0.958 |

结论：静态偏移权重过高，风险模式持续介入；不接受。

### v2：收紧静态偏移阈值

### v3：动态残差主导、前方障碍优先

v3 先改了风险残差公式，但尚未把风险模式从语义障碍动作中隔离。

| 指标 | all_semantic | risk_hysteresis |
|---|---:|---:|
| Task | 11/24 | 6/24 |
| Strict Safe | 3/24 | 1/24 |
| RSafe | 6/24 | 2/24 |
| 壁接触 s/局 | 42.371 | 37.516 |
| 静态事件/局 | 3.833 | 3.333 |
| 动态事件/局 | 1.208 | 1.583 |

结论：动态分数降低壁接触，但语义接口冲突仍存在；不接受。

### v4/v5：语义障碍优先 + 退出后不立即重武装

v4 修正前方障碍优先级；v5 增加退出后必须回到 `risk_rearm_offset_fraction` 以下才允许再次进入。v4 与 v5 的任务结果相同，v5 仅减少部分重复切换。

| 指标 | all_semantic | risk_hysteresis v5 | delta |
|---|---:|---:|---:|
| Task | 11/24 (45.83%) | 12/24 (50.00%) | +4.17 pp |
| Strict Safe | 3/24 (12.50%) | 1/24 (4.17%) | -8.33 pp |
| RSafe | 6/24 (25.00%) | 6/24 (25.00%) | 0 pp |
| 壁接触 s/局 | 42.371 | 26.676 | -15.695 |
| 最长连续壁接触 s/局 | 15.709 | 10.979 | -4.730 |
| 静态事件/局 | 3.833 | 2.750 | -1.083 |
| 动态事件/局 | 1.208 | 1.208 | 0 |

按解剖看，风险模式改善 `mca_m1_lvo` 的任务完成和壁接触，也改善 `basilar_vertebral` 的严格 Safe；但 `popliteal_calf_dvt` 从严格 Safe `3/6` 降至 `0/6`、Task 从 `5/6` 降至 `2/6`，因此不能部署替换。`pulmonary_saddle` 的 Task 未改善，主要风险仍是几何/局部通道失败。

## 决策

不把 `risk_hysteresis` 作为全局默认控制器，不启动 84 场景全量验证，也不宣称 RL/DAgger 学习效果改善。当前实现和全部 pilot 结果保留，作为后续研究的可复现实验。

下一步若继续，应优先解决“何时允许局部风险护盾影响任务进展”的接口问题，例如把风险模式限定为短时、事件绑定的恢复动作，并加入显式的 route-progress 退出条件；不能继续只调风险阈值。

### v6：修正纯外向命令的切向 fallback

在最终实现中修复了一个执行细节：当外向分量被完全削弱时，guard 现在使用切向/航向作为前进 fallback，而不是只输出内向纠偏。v6 使用与 v5 相同的四场景、24 个 paired episodes。

v6 仍未通过安全门槛，尤其 `popliteal_calf_dvt` 严格 Safe 为 `0/6`、Task 为 `2/6`，而基线分别为 `3/6` 和 `5/6`。不启动 84 场景扩展，不替换默认控制器。
