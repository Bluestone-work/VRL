## 本项目应该比较什么

当前上层和底层都用 PPO 更新，因此“用了强化学习”或“换个 PPO 网络”本身不是本项目已证明的创新。要检验的是：在相同测量与执行限制下，事件式优先级学习、时间抽象和时序低层控制是否带来可重复收益。

### A. 已完成的 52 次 pilot：开发检查，不是完整算法比较

- N=1 顺序清除：方法 1 的系统对照；匹配总催化率代理。
- 强测量 balanced_1s：保留已有强启发式表现与机制。
- 规则 V-CTPG：相同测量图、退让能力、预约约束和安全投影的核心非学习基线。
- High-only、Low-only、Both：四格学习贡献消融；保留 untrained 一致性检查。

这个矩阵只解决第一轮开发问题，缺少下面 B/C 的算法级学习比较，不能单凭完成 52 行就称论文对比完整。为保留既有预登记，本次不临时把新臂加入冻结 EXP0053。

当前实测：共同替代运行时下 9/9 训练与 52/52 评估完成；四个开发场景中所有学习检查点的最终状态与规则 V-CTPG 一致，没有学习增益。权威结果为 `../validation/EXP0053_TPG_GENERIC_STUDY_20261004/REPORT.md` 与 `AUDIT.json`；原运行时失败保留。它们不包含 MAPPO、IPPO 或 MAT。

若正式论文要把提升归因于“多集群并行本身”，还需要控制方法一致的数量对照：先比较 N=1/N=3 的规则控制，再补 N=1 专门训练的低层学习策略与 N=3 学习策略。不能只比较单集群规则法与多集群学习法，就把所有提升归因于并行。当前 N=1 学习训练入口/预算尚未接入，必须在后续新协议中实现；单集群评价可运行不代表单集群学习对照已完成。

### B. 下一阶段：多智能体学习作为主算法对照

研究中的一个 agent 对应一个受控磁性集群，不能用集群内部粒子数量冒充协作智能体数量。当前高层读取团队测量图并输出联合通行排列，是集中协调；多集群任务不自动意味着已实现完全分散执行。PPO 是更新算法，用 PPO 训练联合策略与实现 MAPPO 也不是同一件事。

| 优先级 | 基线及拟用适配 | 必须对齐的内容 / 可回答问题 |
|---|---|---|
| 主基线，先实现 | Recurrent MAPPO，measurement-only 适配 | 协作策略与集中价值估计的强参照；critic 只汇总合法测量/历史。检验专门的图与层级结构是否优于一般多智能体协作学习 |
| 主基线，同批实现并核验区别 | Recurrent IPPO，measurement-only 适配 | 同样的 actor 输入与动作能力，按 agent 的可用信息估计价值。检验独立 PPO 学习是否已足够；不能以人为减少通信制造劣势，也不能默认参数不共享 |
| 第三个强主对照 | MAT（Multi-Agent Transformer）适配 | 用多智能体观测到联合动作的序列建模检验协作表征；优先于把单集群 Turbo 当成完整多集群对照。序列次序、通信/动作依赖及相同历史输入都需明确，不能把跨 agent 序列直接当作时间记忆 |
| 辅助结构对照 | 非分层联合 Recurrent PPO（GRU） | 同一集中测量范围、联合通行权限与低层候选；与分层方法比较时间抽象。它不是 MAPPO 的替代名称 |
| 补充网络对照 | PPO-MLP / Transformer-PPO（Turbo 启发的 3D 适配） | 检验时序表示。区分单帧消融与同历史网络比较；未经作者实现核验，不能称原版 Turbo 已复现 |
| 条件性补充 | DreamerV3 | 当主张学习动力学、想象规划或样本效率时应优先纳入；当前下一步测量速度辅助头不等同世界模型或 MBRL，不因有预测头就宣称应享有 Dreamer 的能力 |

上述 recurrent / measurement-only / 血管接口均是本项目拟做的适配，不能把原论文结论当成这里的效果，也不声称列举的是 2026 年全部最新或最强方法。优先顺序为 MAPPO + IPPO 的接口与学习核验，再接入 MAT；增加算法名称不能代替充分训练与调参。

算法依据（2026-10-04 核对第一手原文）：

- Yu et al., *The Surprising Effectiveness of PPO in Cooperative Multi-Agent Games*, NeurIPS 2022，arXiv `2103.01955`。主文 §3.2 区分集中价值输入的 MAPPO 与局部策略/价值输入的 IPPO；§3.3 说明同质 agent 可共享参数；§4.2 用各 agent 局部观测拼接构造集中输入。因此集中 critic 不必依赖额外模拟器真值。§4.1 同时规定相当的调参搜索规模。来源：`https://papers.nips.cc/paper/2022/file/9c1535a02f0ce079433344e14d910597-Paper-Datasets_and_Benchmarks.pdf`。
- Schroeder de Witt et al., *Is Independent Learning All You Need in the StarCraft Multi-Agent Challenge?*, arXiv `2011.09533`，独立 PPO/局部价值估计的原始参考。来源：`https://arxiv.org/abs/2011.09533`。
- Wen et al., *Multi-Agent Reinforcement Learning is a Sequence Modeling Problem*, NeurIPS 2022，arXiv `2205.14953`。将多 agent 观测序列映射为动作序列，适合作为本项目拟定的联合协作学习参照；其基准表现不保证血管任务优势。来源：`https://proceedings.neurips.cc/paper_files/paper/2022/hash/69413f87e5a34897cd010ca698097d0a-Abstract-Conference.html`。

### B1. 先固定信息与控制接口，避免形式上的 MARL 对比

1. **Actor 和 critic 分别审计。** 仅允许合法的带噪/延迟观测、检测新鲜度、可观测连通关系和指令历史。集中汇总测量不等于读取真实位置、真实剩余血栓质量、全局真实血管图或真实流场。训练奖励和独立评价仍用真值，声明仍是“无导航真值”，不是“全链路无真值”。
2. **同样的测量通信权限。** 当前主方法高层看到团队测量图，主对照必须有同等访问机会。为每个方法分别列 actor/critic 字段、历史窗口、通信内容、延迟、频率及成本。若另测完全分散执行，主方法也必须受相同通信限制，单独成表。
3. **MAPPO/IPPO 不能只改标签。** 若 actor 输入已经含完整团队观测/历史，IPPO 的“局部”输入与集中 critic 可能实质相同。先核验实际字段和历史差别；若相同，应承认两者退化为相同信息条件下的 PPO 变体/重复对照，不通过删基线观测制造区别。标准局部 actor 的 MAPPO/IPPO 比较需在所有方法对齐的分散信息设置下进行。
4. **相同可达控制能力。** 当前低层是 `marl/tpg_learning.py` 中的 9 个离散三维残差/保持/退让候选，不是任意连续磁场电流。主学习对照也须能表达可行通行选择及相同局部控制；不能只让基线选低层动作，而让主方法额外学通行顺序。目标分配和事件触发目前仍是手工规则；新适配必须披露其共享或替代范围。
5. **系统比较与模块归因分开。** 系统表统一传感、驱动限制和基础安全投影，各方法采用各自协调策略，不强行把完整 V-CTPG 高层塞给所有方法后再声称图结构有收益。模块表固定同一 V-CTPG 预约/候选接口，替换规则、高层学习、低层学习；其收益只归于替换模块。若只实现了 common-TPG MAPPO-low，必须如此命名，不能冒充完整 MAPPO 系统比较。
6. **强基线有同等机会。** 用相同训练物理步预算、训练/开发/测试划分、奖励、初始化/先验可用性和调参次数；报告实际高层决策样本数、网络规模与耗时，不把一个联合控制步乘 agent 数伪装为更多独立环境交互。方法可有各自合理超参数；控制频率/事件节律差异单列，并做匹配节律的归因对照。

这些要求是新 MARL 实验的准入条件，尚未完成接口实现与泄漏审计。2 mm 间距仍是未标定的仿真代理，匹配安全层也不能证明真实磁场无相互影响。

### C. 强传统规划对照

- 事件式测量优先级/预约规划：必须有等待、主动退让、重新排序能力。
- 部分观测滚动路径/预约搜索或测量模型 MPC：只用可观测连通图；未知区保持未知；不同分支的冲突仍用 3D 欧氏距离。
- RRT*/Dijkstra 可作为路径层组件，但单独一条几何路径不解决多集群时序冲突，不能拿缺失协调/执行层的算法当完整弱对照。

适配时要为传统和学习方法提供同样的误差、驱动限制和共同安全层；全真值全局规划只可做单列 oracle 诊断。

## 对齐预算、指标和论文主张

1. 算法比较同时看同环境交互预算下的学习曲线、最终性能、训练墙钟/硬件与推理延迟。模型式方法另报模型训练和想象计算，不能只看较少真实交互而隐藏计算成本。
2. 同一正式预算用于可比学习臂，预先规定检查点和调参规则。先导 8192 步是管线/机制开发预算，不是已经充分训练的证明。Turbo 补充材料记录 5 亿环境交互步；这个数说明预算语境不同，不能直接照搬，也不能将本项目短 pilot 的失败解释成学习理论上无效。
3. 主指标沿用安全清除定义，另报 AUC、T90 达到率/删失、最小欧氏距离、违规暴露、壁面接触、等待/停滞、决策次数与全部计算开销。不能只用训练 reward 决定谁赢。
4. 固定配对布局、全种子、失败记录和独立确认集仍按 `VCTPG_EVALUATION_PLAN_20261004.md`。论文采用的平滑训练曲线误差带、最后 50 回合或人机配对 t 检验，不自动适用于本项目跨训练种子/场景的推断单位；不能机械照抄。
5. 本文新增的是基线选择方案；所有 B/C 的未实现内容均保持“待实现/待验证”，没有新增性能结果。实验启动仍按运行时准入先行，旧失败不被新运行替代。
