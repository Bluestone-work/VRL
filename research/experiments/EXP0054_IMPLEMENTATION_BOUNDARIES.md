# EXP0054 实现与归因边界

本轮是开发性 shared-TPG 多智能体学习比较。MAPPO/IPPO 的独立规划器系统表和 MAT 尚未完成；不能称已完成所有论文主对照。

| 内容 | 实际实现 |
|---|---|
| Actor 观测 | 自身六帧测量历史 + 当前团队节点和成对信息。图 actor 的每个分数只读该 agent 的历史与其他 agent 的当前测量，然后联合排序。MAPPO/IPPO 分别提交离散优先级 bids，经过同一不可抢占拓扑排序 |
| MAPPO / IPPO 区别 | Actor 初始化与信息范围相同。前者 critic 池化所有 agent 的测量历史；后者只用自身历史与相同当前团队包。后者是允许通信的 IPPO 适配，不是严格孤立局部观测版本 |
| 分层时钟 | 高层只在手工事件处决策；低层每个物理控制步决策。事件累计达到 32 个后在完整事件边界更新；未结束事件不伪造成额外样本 |
| 低层动作 | 同九个残差、保持、退让候选与有效性掩码；各方法都经同一测量安全投影 |
| 改善假设 | 下一次滤波测量速度预测显式参与候选打分；no-AC 令这些特征及其监督损失为零。两者共享模型尺寸、其余训练规则与相同高层 |
| 共同训练修订 | 逐 agent PPO 比率和损失，集中/局部测量 critic；这些算法适配不是本项目新发明。当前尚无 value normalization 调参或收敛证明 |
| 监督来源 | 下一次新鲜个体测量、实际请求指令；模拟器结果只用于训练奖励和独立评分。部署策略没有真实质量、流场或路径输入 |
| 安全边界 | 相同 2 mm 空间约束代理与原安全成功定义；非磁场标定、非无碰撞证明 |

动作条件预测用投影后请求指令作为训练标签条件，而部署候选打分先于最终联合投影。投影频繁改变命令时，这种接口差别可能限制预测用途；需检查干预次数，不能宣称预测了精确执行动作。预测目标是延迟滤波测量速度，并非已识别真实物理动力学。

本轮高层动作参数化不同：MAPPO/IPPO 为每个 agent 三档 bids（含冗余组合），图策略为联合可行排列。表达全部可行通行顺序已测试，但随机探索分布并不相同，不能声称严格同分布初始化。低层名义偏置一致，所有确定性未训练网络须通过与规则的全时域轨迹一致性。

准入包含 42 项相关测试和真实回合检查。受控真值容器扰动验证了控制包提取和策略边界，不证明共享传感器能直接迁移到实物；合成几何、目标 ID、标定和驱动仍需实物验证。

运行时间是当前实现的端到端开销，包含未做部署裁剪的价值网络调用和环境步骤。不得将其当作优化后的纯 actor 推理延迟来宣称计算优势。

预算：4 变体 × 3 种子 × 32768 控制步；8192/32768 全部保留。固定八个开发场景，216 次主评估，另有 10 次预检与 4 次 2048 步训练回归。所有确认集继续关闭；基线和改进方法无额外挑选有利布局或种子的权利。

后续改善依据：旧奖励中多清除 1 个百分点的即时正收益等价于 27 集群·秒的壁面罚项，而注册安全定义要求壁面累计小于 1 集群·秒。该量纲诊断提示目标可能不匹配；它不是调大奖励权重必然改善的证明。当前运行保持冻结奖励，后续若做安全奖励/成本归因实验，必须独立登记并让 MAPPO/IPPO 与拟议方法共同使用。
