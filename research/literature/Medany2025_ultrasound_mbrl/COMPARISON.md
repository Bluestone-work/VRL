# 论文与当前 MCA 任务的对照

核对日期：2026-09-30。论文：Medany M. 等，*Model-based reinforcement learning for ultrasound-driven autonomous microrobots*，Nature Machine Intelligence 7, 1076–1090，2025-06-26，DOI: 10.1038/s42256-025-01054-2。

原文：[Nature](https://www.nature.com/articles/s42256-025-01054-2)，[PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC12283351/)，[作者仓库](https://github.com/M-Medany/Model-Based-Reinforcement-Learning-for-Ultrasound-Driven-Autonomous-Microrobots)。全文XML与作者README已保存到同目录，来源及SHA256见 sources.json。以下基于主文和README，未审计作者环境源码：GitHub递归API遭遇限流，补充PDF下载失败。

## 原文能够支持的结论

1. **策略知道目标位置。** Methods → RL implementation 明确把状态写成处理后的图像、当前位置和目标坐标。仿真图像也标记目标。因此是目标条件导航，不是目标未知的盲搜。知道终点并不等于知道可行路径、动作后果或已经学会控制。
2. **仿真主要是二维图像导航。** Results → Simulation environment：Pygame，64×64×3 RGB观测，通道/障碍/机器人/目标可见，重点是局部路径规划和避障；PZT共振、微泡大小等复杂动力学刻意不在这一仿真中完整建模。不能把其仿真等同高保真流固声耦合。
3. **训练和规划画面不等于部署时盲目探索。** 作者README及 Supplementary Video 1 描述早期训练失败、后期目标获取改善。Supplementary Video 3 的左侧蓝色树枝是RRT*搜索、红色为找到的路径；右侧才是微机器人跟踪更新目标。Dreamer的潜空间想象又是另一种模型内采样，不能混作物理随机游走。
4. **成功率随实验条件变化。** 论文 Main 与作者README报告跨已训练通道约90%，未见通道最初约50%、额外训练后约90%；Results → Transition 描述仅实物图像训练的较低目标获取表现。不能拿其中某个70%或90%直接对照我们的固定解剖、理想执行器清栓率。
5. **奖励含到达、碰撞及距离项。** Methods → Reward function 与 Algorithm 1/2：奖励目标到达、惩罚碰撞，包含距离反馈；流动版本还有鼓励靠壁等处理。实物控制涉及PZT频率/振幅、视觉追踪、装置和微泡响应不确定性。论文不同版本的碰撞/终止处理并不完全相同，不宜声称它们一律撞一下就终止。

## 当前实现的简化与实际审计

- EXP28 原来四个血栓固定在 station 8/14/21/48，只随机了机器人、粒子及流量。此项未满足用户“全部位置随机”的意图，EXP29 已修正。
- actor得到精确位置、流速、到当前最近目标的方向和血管测地距离；critic另见四个血栓的位置/质量。未模拟成像噪声、遮挡或延迟。5个机器人有独立理想速度控制，不是共用一个真实声场的耦合控制。3D和数量更多不自动意味着学习更难。
- EXP28粒子是半径0.02 mm的随流软障碍，接触只扣2 reward/机器人秒/重叠粒子，无刚体碰撞反力、无碰撞失败条件；完成有30团队奖励。旧actor只看到最近一个粒子。这给出了忽略短暂碰撞的可能性。
- 精确复核三个100万步策略的相同20个验证布局：完整清除56/60=93.33%，无粒子接触且无机器人流失的完整清除27/60=45%；有粒子接触的回合30/60。seed42单独清除20/20并不代表三种子都100%，更不代表无碰撞。证据：`research/runs/EXP_0028_MCA_RANDOMIZED_20260930a/safety_audit_1000000.json`。
- 渲染把机器人放大4倍、粒子放大6倍，视觉球体交叠不必然是物理接触。不过上述接触来自实际物理半径的日志，确实存在。EXP29回放新增实际接触标红与S键真实尺寸。

## EXP29 已实现的对应修正

- 每回合同时重采样四个血栓、五个机器人、32个粒子。血栓随机于可通行分支内的离散中心线节点、离端点>1 mm、四点分离；不是任意壁外点。分支水力阻力与目标距离场同步重建。相同显式seed仍可复现。
- 从36维扩成76维观测，新增四个按未来1秒最小间隙排序的粒子特征：相对位置/速度、当前间隙、最近接近时间、预测间隙及mask。这里是确定性运动学预警特征，**不是训练了世界模型**，也不替策略产生动作。
- 碰撞事件扣6，接触时间扣20/机器人秒/粒子，0.15 mm安全邻域内加入平方接近代价1/秒；碰撞回合不发团队完成奖励。它们是透明的工程奖励超参，不是物理损伤或真实临床风险参数。
- 完整清除和“零动态粒子接触、全机器人保留的完整清除”分别报告。后者仍不等于零壁接触、零机器人间接触或临床安全。独立评估从20增至100种固定验证布局，各种子/检查点复用；并非密封最终测试集。
- 仍然是共享流场中的软障碍，没有新增未经验证的弹性碰撞/粘附力；后续若研究真实接触阻挡，需要单独的接触力学模型及数值验证。仍只是一种MCA解剖，不把当前结果称为跨血管泛化。

结论：应修正漏掉的随机化与安全指标，让任务与需求一致；不应为了让百分比低于论文而任意增加难度或降低成绩。
